## Package facts

Only what the code can't tell you: design decisions, engine gotchas found here, where test assets live.

- Editor tool: the product is the editor window (`Editor/UI/TextToAnimationWindow.cs`). The runtime assembly
  (`Code/TextToAnimation/Core`) is plain C# shared with the editor; there are no Components.
- The UniMate weights (769 MB) are downloaded by the user at run time, not shipped and not in this repo.
- Test fixtures (47 MB, committed) live in `tests/TextToAnimation.Tests/fixtures` and are generated by the
  Python/Blender scripts in `dev/tools` from upstream UniMate. Never edit them by hand.
- s&box declares `Vector3` in the global namespace: Core files that use `Vector3` carry
  `using Vector3 = System.Numerics.Vector3;` after the namespace line (see `Code/TextToAnimation/Assembly.cs`).
- The real whitelist proof is `dev/editor-rig/run_gate.ps1` (drives a real sbox-dev.exe through
  `Editor/Testing/EditorGate.cs`); `dev/editor-rig/*CompileCheck.csproj` are fast offline pre-checks.
- `Editor/Mapping` is a vendored copy of humanoid-retargeter's mapping code (also in `Core/Mapping`).
